# Git Playground 🛝

A safe sandbox for practicing Git and GitHub. **Nothing here counts.** The whole point
is to experiment, make mistakes, and get comfortable. You can't break anything that matters.

Use this repo with (Guide 2) Practice the Git Loop "01-practice-loop.md" (in the S617 workshop repo) to try:

- **The everyday loop:** fork -> clone -> edit -> commit -> push -> pull request
- **Time travel:** going back to an older commit, then returning to the present
- **Branching:** making a separate line of work and merging it back

## Where to work

Add your **own** file in the [`practice/`](practice/) folder - name it after yourself,
like `practice/alex-rivera.md`. Because everyone works in their own file, nobody's
changes ever collide.

Go break something (safely). ;D
