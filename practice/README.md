# practice/

Create **your own** file in this folder and do whatever you like with it.

1. Name it after yourself: `your-name.md`
2. Write anything - a hello, a list, some notes or A - B - C - D just to mark your changes.
3. Then practice committing, travelling back through history, and branching
   (follow Guide 2 "01-practice-loop.md").

> **Only edit your own file.** Leave everyone else's alone - that's what keeps the
> sandbox conflict-free, and it's the same habit you'll use on the real project.
